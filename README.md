# NJ-07 Demographics

An interactive map displaying demographic and voter registration data for New Jersey's 7th Congressional District.

## Data Sources

The demographic and voter data layers presented in this map are sourced from the following:

* **% Hispanic/Latino:** American Community Survey (ACS) 2024 5-year estimates (Census tracts within NJ-07).
* **Young voters (% age 18–34):** American Community Survey (ACS) 2024 5-year estimates (voting-age population).
* **Registered Democrats, Republicans, and Unaffiliated Voters:** NJ Division of Elections Statewide Voter Registration System (SVRS). *(Note: Currently utilizing placeholder data for demonstration purposes).*

## Development

This project is built using Vue 3, Vite, and Leaflet.

### Setup

```bash
# Install dependencies
npm install

# Start the development server
npm run dev

# Build for production
npm run build
```
